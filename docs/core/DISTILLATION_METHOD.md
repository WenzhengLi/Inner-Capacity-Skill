# 蒸馏方法：从女娲 Skill 到用户自身

## 女娲 Skill 的蒸馏方式

女娲 Skill 的核心不是“模仿一个人的语气”，而是提取一个人稳定可复现的认知结构。

根据公开仓库说明，它的蒸馏流程可以概括为：

1. 明确蒸馏对象和输出目标
   - 先判断要蒸馏的是人物、关系、团队、心智模型、工具方法，还是用户自己。
   - 不同对象需要不同采集路径，不能用同一套模板硬套。

2. 建立资料目录
   - 为对象创建独立目录。
   - 将原始材料、分析过程、最终 Skill 分开管理。
   - 避免把素材、判断和成品混在一起。

3. 多源采集
   - 著作、公开讲话、访谈、播客、文章、社交媒体。
   - 他人评价、批评、传记、第三方观察。
   - 重大决策、人生节点、失败样本、转折样本。
   - 目的不是收集越多越好，而是拿到足以还原思维结构的材料。

4. 提取表达 DNA
   - 关注用词、节奏、句式、比喻、常用概念。
   - 但表达只是外层，不应停在“像不像”。

5. 提取心智模型
   - 看对象如何定义问题。
   - 如何排序价值。
   - 如何判断机会、风险、关系和长期收益。
   - 如何在不确定、压力和诱惑下做决定。

6. 提取决策启发式
   - 对象反复使用哪些判断规则。
   - 哪些情况下会拒绝、等待、下注、转向或退出。
   - 哪些边界是稳定的。

7. 提取反模式
   - 对象不相信什么。
   - 不做什么。
   - 认为哪些行为危险、浅薄、低效或自欺。

8. 建立诚实边界
   - 公开表达不等于真实想法。
   - 文字材料不等于完整人格。
   - 能提取框架，不等于能复制直觉、生命经验和隐性能力。

9. 验证蒸馏质量
   - 跨场景是否能复现。
   - 是否能生成新的判断，而不只是复述语录。
   - 是否有排他性：换成另一个人不会同样成立。
   - 是否知道自己不能确定什么。

## 如何蒸馏用户自己

蒸馏用户自己，不应只复制当前的语言习惯和情绪惯性。否则得到的只是“旧我自动化”。

更好的目标是蒸馏出三个层次：

1. 当前的我
   - 真实的思维方式、欲望结构、行动模式、反复困境。
   - 这一层用于诊断，不用于盲目强化。

2. 更高版本的我
   - 用户真正认可、愿意靠近的判断标准、价值排序和行为原则。
   - 这一层用于训练和对话。

3. 可重构的成长系统
   - 随着用户回答、行动和复盘，不断调整对用户的理解。
   - 这一层用于长期迭代，避免把用户固定在某个旧标签里。

## 用户自身蒸馏的数据来源

第一阶段可以先收集以下材料：

- 50 个评估问题的回答
- 最近 3-5 个重大选择
- 最近 3-5 个反复出现的痛苦
- 最近 3-5 次让用户后悔的行为
- 最近 3-5 次让用户觉得自己变强的行为
- 用户对金钱、关系、身体、事业、自由、名声的真实排序
- 用户面对诱惑、压力、羞耻、嫉妒、失败时的反应
- 用户反复说的话、反复逃避的问题、反复向往的生活
- 亲近他人对用户的评价，尤其是重复出现的评价
- 用户想成为的人，以及用户不想再成为的人

## 蒸馏用户自己的流程

1. 初始访谈
   - 让用户回答 50 个评估问题。
   - 不急着评分，先收集原始回答。

2. 模式提取
   - 从回答中提取高频主题。
   - 标记欲望、恐惧、价值排序、行动瓶颈和自我叙事。

3. 阴阳映射
   - 将用户追求的外在目标归入“阴”。
   - 将用户承载这些目标所需的能力归入“阳”。
   - 检查是否存在阴超过阳、阳被忽视、阴被妖魔化、阳被空谈化等模式。

4. 盲区检查
   - 反问：这个问题一定是阳不足吗？
   - 是否有结构、环境、信息差、资源约束、阶段错配、关系系统等因素？
   - 是否需要引入芒格、纳瓦尔、系统论、认知行为、斯多葛、佛学、博弈论等其他模型？

5. 阶段判断
   - 判断用户当前更接近求阴、失衡、补阳、阳生阴，还是阴阳互化。
   - 阶段判断只作为临时地图，不能作为身份标签。

6. 生成成长画像
   - 当前主要矛盾。
   - 稳定优势。
   - 重复短板。
   - 自欺模式。
   - 最值得训练的 1-3 个阳维度。

7. 生成对话人格
   - 先冻结一份用户已有思维模型清单，不因生成新版而丢失旧模型。
   - 从人物蒸馏库中寻找现阶段可能产生乘数效应的扩展模型。
   - 给出来源、适用场景、反作用和不选择其他模型的理由。
   - 与用户讨论并标记批准、试用、拒绝或暂缓。
   - 只有批准后才生成对话人格；用用户能接受的语言说话，保留温度但不纵容逃避。
   - 用模型帮助用户扩展，而不是用模型压住用户。

8. 行动闭环
   - 每次对话给出 3-7 天的小训练。
   - 下次复盘训练结果。
   - 根据真实行动修正画像，而不是只根据自我描述判断。

## 人物蒸馏库扩展原则

扩展不是按用户每个短板找一个名人对应，也不是把所有名人模型堆进Skill。

正确方法：

1. 判断用户当前阶段最重要的认知瓶颈。
2. 查看用户已有模型，避免继续强化已经过强的能力。
3. 从蒸馏库寻找能改变整个判断链的少数模型。
4. 检查人物模型的证据、内在张力和诚实边界。
5. 组合模型时明确每层负责什么，避免概念重叠。
6. 经用户讨论批准后进入试用；有行为证据后才升级为用户已有模型。

高质量扩展应回答：

- 它改变了用户哪个关键问题的定义？
- 它让用户新增了哪一个以前不会问的问题？
- 它如何与用户已有模型组合，而不是取代已有模型？
- 它在什么情况下会产生反作用？

## 质量标准

一个好的“自我蒸馏 Skill”应该满足：

- 能指出用户真实模式，而不是只重复用户想听的话。
- 能区分当前的我和更高版本的我。
- 能把抽象价值观转化为可执行训练。
- 能识别用户在追阴、补阳、阳生阴之间的阶段变化。
- 能承认不确定性，允许核心世界观被事实重构。
- 能保护用户主体性，不替用户决定人生。

## 关键警惕

自我蒸馏最危险的不是“不像”，而是“太像旧我”。

如果 Skill 只是复制用户的焦虑、欲望、解释习惯和逃避方式，它会让旧模式更稳定。真正有价值的蒸馏，应该把用户从旧模式中看见出来，并帮助用户训练一个更清醒、更有承载力的自己。
