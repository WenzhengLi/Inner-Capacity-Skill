# 故事训练计划

用途：让【讲故事】不再随机抽模型，而是按“本周主线 -> 每日模块 -> 相关模型组”训练。故事仍默认一次只讲一个主概念，避免信息过载。

## 训练原则

- 每周设置 2-3 个主训练模块。
- 每天选择 1 个主模块，最多带 1-2 个关联模型作为辅助理解。
- 故事正文只点破 1 个主概念；关联模型只用于选题和应用，不在故事里铺开讲。
- 如果用户当天有强上下文，例如代码评审、身体反馈、关系冲突、消费冲动，则优先当天真实上下文。
- 如果用户说“讲故事，某主题 / 某流派”，优先用户指定。
- 如果用户回答了开放作业，下一次优先从其薄弱点继续训练。

## 模块库

| 模块 | 训练目标 | 可关联模型 |
|---|---|---|
| 工作推进 | 把事情切小、推进、交付、复盘 | 任务切片、验收标准、可观测交付、瓶颈思维、停止规则 |
| 技术成长 | 提升架构判断、测试意识、工程化能力 | 接口归属、低耦合、依赖倒置、characterization tests、回滚边界 |
| 身体底盘 | 维护睡眠、精力、饮食、恢复能力 | 能量预算、最小恢复动作、环境设计、损伤不可逆、欲望延迟 |
| 金钱欲望 | 管住消费、奖励、证明欲和现金流 | 预先承诺、机会成本、欲望升级、现金流安全垫、身份消费 |
| 关系沟通 | 理解情绪、边界、需求和修复 | 情绪翻译、关系账户、边界感、修复尝试、投射识别 |
| 情绪自控 | 处理愤怒、逃避、羞耻、负罪感 | 情绪命名、暂停按钮、视角拉远、身体先行、触发器识别 |
| 轻创业 | 低成本验证真实痛点 | 能力圈、JTBD、MVP、渠道验证、现金流优先、非遍历性风险 |
| 风险边界 | 避免不可逆损失和上头决策 | 非遍历性风险、停止规则、回滚边界、安全垫、杠铃策略 |
| 自我认知 | 分清真实能力、标签、欲望和身份 | 能力圈、特定知识、认知诚实、身份证明陷阱、自我欺骗 |
| 长期主义 | 训练耐心、复利、稳定规则 | 延迟满足、复利、过程指标、长期反馈、反脆弱 |
| 人性的弱点 | 识别人如何被第一印象、认知成本、面子、恐惧、惰性和自我辩护牵引 | 入口信号、低成本被理解、判断捷径、损失厌恶、虚荣驱动、自利性偏差 |

## 每日选择规则

1. 先看当天日期对应的主模块。
2. 再看用户最近 3 条消息，如果有更强真实上下文，则覆盖默认模块。
3. 在关联模型组中选择 1 个主概念讲故事。
4. 相邻故事的 `立意方向` 最多连续两个相同；如果最近两次故事的非空 `立意方向` 相同，下一次必须换方向，除非用户明确指定继续该方向。
5. 故事后作业必须能验收该模块是否迁移到用户真实生活。
