# 评估问题模板库

本文件是动态 50 题的模板库和灵感池，不是固定题单。

使用规则见 `docs/protocols/ASSESSMENT_PROTOCOL.md`：

- 每个人的 50 题都应该不同。
- 每次生成 3 道题。
- 每组题围绕一个主方向，并允许穿插辅助方向。
- 优先根据 `user-space/PROFILE.md`、最近对话和已回答内容改写问题。
- 生成过的问题保存到 `user-space/GENERATED_QUESTIONS.md`。

## 通用题型

每 3 道题建议包含：

1. 事实题：最近一次真实事件是什么？
2. 判断题：你当时为什么那样想 / 选 / 反应？
3. 复盘题：现在回看，这暴露了什么模式、代价或训练点？

## 方向模板

### 价值排序

- 当两个重要东西冲突时，你通常牺牲哪一个？最近一次是什么？
- 你嘴上说重要，但行动里经常排到后面的东西是什么？
- 如果一年后回看，今天什么选择最值得？

### 身体底盘

- 最近一周，身体在哪个时段最拖你后腿？
- 当身体差时，你最容易做出哪类错误决定？
- 你现在最需要修的一个身体习惯是什么？为什么不是别的？

### 金钱欲望

- 最近一次消费，哪些部分是工具，哪些部分是奖励，哪些部分是证明？
- 你现在的现金流安全垫够不够支撑你的野心？
- 什么情况下你必须停止一项花钱行为？

### 工作推进

- 你今天 / 本周最小可交付物是什么？
- 什么事情看起来忙，但其实没有推进主线？
- 谁能验收你这件事完成了？

### 关系沟通

- 最近一次沟通不顺，你听到的是对方的话，还是自己的防御？
- 你在关系中更容易过度付出、索取、控制、逃避，还是沉默？
- 如果重来，你会先接住对方哪一个情绪？

### 风险意识

- 这件事最坏情况是什么？是否会造成不可逆损失？
- 你的小亏边界是什么？什么时候必须停手？
- 哪些东西是井绳，不能拿去试错？

### 自我认知

- 你现在最想证明给谁看？为什么？
- 你真正的旧扳手是什么，也就是能解决具体问题的能力？
- 你不想再成为过去哪个版本的自己？
