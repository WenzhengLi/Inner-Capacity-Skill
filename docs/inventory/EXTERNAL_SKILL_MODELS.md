## 成熟 Persona Skill 的通用结构

这些成功 Skill 基本不是“模仿语气”，而是提炼一个人的认知操作系统。

常见结构：

1. 角色边界：说明这不是本人，而是基于公开材料提炼的视角。
2. 回答工作流：先分类问题，再决定是否需要研究事实，最后调用模型回答。
3. 心智模型：通常 3-7 个，是该 Skill 的核心。
4. 决策启发式：通常 5-10 条，用于具体判断。
5. 表达 DNA：句式、语气、节奏、类比、幽默、禁忌。
6. 价值观与反模式：明确追求什么、拒绝什么。
7. 诚实边界：承认无法复制直觉、私下想法和未公开经验。
8. 失败模式：列出“最容易被错误模仿成什么”。
9. 快速参考：这个人会先问什么、不会做什么。

对 Inner Capacity Skill 的启发：我们的 Skill 也应采用类似结构，但对象不是某个名人，而是“成长型诊断与训练系统”。它不能只会说阴阳，而要有模型路由、诊断流程、说话方式和训练闭环。

## 成功人士 Skill 的核心思维模型

### 芒格

核心模型：

- 多元思维模型
- 逆向思考
- Lollapalooza 效应
- 能力圈 + 意见资格制
- 激励机制决定行为

适合补足：

- 能力圈不清楚。
- 没有“不要做清单”。
- 容易“成年人全都要”导致资源分散。
- 需要把复杂问题拆成多模型判断，而不是只凭一个角度。

### 费曼

核心模型：

- 命名不等于理解
- 反自欺原则
- 不确定性是力量
- 具象化思考
- 深度游戏

适合补足：

- 把“认知”从听过概念，推进到真正理解。
- 把抽象高度拉回具体事实。
- 区分“我理解了”与“我能解释、能验证、能行动”。
- 处理用户最在意的 90 天主线：认知。

### Naval

核心模型：

- 杠杆思维
- 特定知识
- 欲望即合同
- 重新定义术
- 痛苦转化为系统性解决方案

适合补足：

- 用户排序是“机会 > 自由 > 钱”。
- 用户目标包含年薪 50 万、外企、更多可支配时间。
- 需要把“自由”从感觉重定义为结构：现金流、技能杠杆、时间控制权、不可替代性。
- 需要把痛苦转成系统，而不是只靠情绪复盘。

### 塔勒布

核心模型：

- 非对称风险
- 反脆弱
- Skin in the Game
- 林迪效应
- Via Negativa，减法优先
- 领域特异性

适合补足：

- 创业的一阶自由与二阶压力。
- 判断不可逆损失。
- 建立“不要做清单”。
- 砍掉短视频、暴食、抽烟等系统脆弱点。
- 区分能试错的风险和会出局的风险。

### 巴菲特

核心模型：

- 经济护城河
- 能力圈
- 市场先生
- 复利滚雪球
- 制度性强制力
- 所有者思维

适合补足：

- 长期复利和身体、英语、技能积累。
- 工作与职业选择中的护城河意识。
- 情绪波动时不被“市场先生”式心态带走。
- 把自己当作长期资产经营，而不是短期状态消耗品。

### 乔布斯

核心模型：

- 聚焦即说不
- 端到端控制
- 连点成线
- 死亡过滤器
- 技术与人文交汇

适合补足：

- 把“全都要”转成“先砍掉什么”。
- 判断顶配显示器、短视频、游戏等是否服务主线。
- 用死亡过滤器处理“我到底要追求什么”。
- 在职业与人生设计中统一体验、效率和意义。

### 张一鸣

核心模型：

- 延迟满足感是认知边界，不是道德品质。
- 把表象问题投影到高维简单问题。
- 算法是工具，同理心才是根。
- Context not Control。
- 逃逸平庸的重力。

适合补足：

- 用户对延迟满足的理解已经接近“认知而非忍耐”。
- 工作推进焦虑，需要把表面任务投影到更简单的系统问题。
- 关系沟通中需要“同理心”，不是只靠道理。
- 管理自己时要用 context，不只靠硬控制。

### Paul Graham

核心模型：

- Writing = Thinking
- 品味即认知工具
- 迭代发现
- 超线性回报
- 独立思考即生存

适合补足：

- 用户喜欢复盘、归类、上升高度。
- 需要把“脑内想清楚”变成“写清楚”。
- 适合做周复盘、决策记录、能力圈地图。

### Karpathy

核心模型：

- 构建即理解
- March of Nines 工程现实主义
- 锯齿状智能
- 不确定性表达

适合补足：

- 用户有软件开发背景。
- 认知训练不能只看书，要通过构建、实践和验证形成。
- 对 AI、技术、职业判断时，适合用工程现实主义而不是概念兴奋。

## 对 Inner Capacity Skill 的组合建议

不建议把所有模型都塞进主流程。第一版可以分层：

核心默认模型：

1. 费曼：把认知落到真正理解。
2. 芒格：能力圈、逆向思考、不要做清单。
3. 塔勒布：风险、减法、不可逆损失。
4. Naval：机会、自由、杠杆、特定知识。
5. 张一鸣：延迟满足、升维简化、同理心。

辅助模型：

- 巴菲特：复利、所有者思维、长期资产。
- Paul Graham：写作即思考、迭代发现。
- 乔布斯：聚焦、减法、死亡过滤器。
- CBT / 斯多葛 / 佛学：用于情绪、执着、关系触发，但不要把它做成玄学。

## 结构迁移到本 Skill

Inner Capacity Skill 后续可以这样写：

1. 使用说明
2. 核心身份：哲学家朋友 + 成长诊断系统
3. 交互硬规则：先沟通、先对齐，再训练
4. 诊断流程：事实 -> 模式 -> 阳维度 -> 阴阳状态 -> 阶段 -> 模型推荐
5. 核心模型库：阴阳主框架 + 外部模型路由
6. 阳维度评分标准
7. 说话方式与点破规则
8. 上中下策输出法
9. 小训练生成规则
10. 诚实边界与反模式
