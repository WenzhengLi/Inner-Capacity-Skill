# Inner Capacity Skill

Inner Capacity Skill 是一个成长型思维模型 Skill。

您好，2026 款傻妞，为您服务。

我们的主要功能是帮助您，通过 50 道题和平时的沟通，蒸馏出您的思维模型，并扩展新的思维模型。我们使用聊天、寓言寓教的故事、日常复盘和具体问题分析，和您沟通，为您解答当前生活中的难题，并和您一起成长。

## 迁移方式

项目分为两层：

- 项目内核：`skills/`、协议、模板和默认训练计划，可提交。
- 个人数据：`user-space/`，默认被 `.gitignore` 排除。

首次使用时，复制模板或让 Agent 自动创建：

```text
templates/user-space/ -> user-space/
```

## 初始化流程

第一次说【开始】时，系统会先介绍自己，然后问 5 个定制问题：

1. 是否愿意开始 50 道题。
2. 希望使用温和陪伴、清醒直接、还是犀利教练模式。
3. 是否偏好某些故事类型。
4. 有什么想主动讲的背景或困惑。
5. 当前推崇什么想法、人物、价值观或生活方式。

之后系统每次给 3 道题。50 题不是固定问卷，而是根据您的初始化回答、最近沟通和已答内容动态生成；每几题围绕一个方向，并穿插其他方向。您可以要求换题，但总题数仍然是 50。做题、讲故事、聊天可以并行，但会持续温和推进 50 题完成。

## 为什么要做 50 题

因为只有拿到足够真实的样本，系统才知道您是什么样的人。后续讲故事、提建议、做训练计划，才更容易贴到您的心里，而不是泛泛讲道理。

具体出题规则见 `ASSESSMENT_PROTOCOL.md`。

也支持【轻量评估】：用 15 题先做初步建模。但 15 题只能得到粗略画像，完整 50 题才更准确。

## 健康与命理

健康和命理默认不启用，只有用户主动请求时启用。

### 健康

触发词：

```text
健康
身体
睡眠
中药反馈
给医生总结
```

健康模块只做：

- 记录睡眠、饮食、运动、用药反馈和身体状态。
- 整理给医生 / 中医师看的摘要。
- 提供低风险生活建议和就医提醒。

健康模块不做：

- 不替代医生诊断。
- 不自行开药、改药、停药。

### 命理 / 算命 / 合盘

触发词：

```text
命理
算命
合盘
国运
人生方向
找房起局
```

命理模块按现有设计支持：

1. 信息确认：出生时间、地点、生平事件、当前问题。
2. 八字反馈：结构、大运、流年、事件校准。
3. 奇门反馈：针对具体问题起局，如找房、合作、项目推进。
4. 姻缘 / 合盘反馈：关系结构、相处模式、冲突点。
5. 伴侣关系反馈：沟通、边界、长期相处建议。
6. 总控详解：综合命理、现实经历、国家 / 行业趋势和当前行动。
7. 输出上中下策、今日最小动作和风险边界。

命理只作为文化视角、象征叙事和人生复盘，不替用户做医疗、法律、财务或重大人生决定。

## 支线任务、聊天分析与功能沉淀

系统支持把平时聊天里的想法分三类处理：

- 聊天分析：先理解用户说了什么，再拆解哪里对、哪里可能想简单了、还能怎么延伸、能总结成什么模型、下一步怎么做。规则见 `CHAT_ANALYSIS_PROTOCOL.md`。
- 支线任务：把值得试一试的小动作登记到 `user-space/SIDE_TASKS.md`，记录任务索引、描述、回答和验收方式。规则见 `SIDE_TASK_PROTOCOL.md`。
- 功能沉淀：只有当某个能力可复用、可迁移、不依赖私人经历时，才写进公开协议、模板和 README。规则见 `FUNCTION_CONSOLIDATION_PROTOCOL.md`。

用户正在看的历史讲解、短视频、人物传记、地域财富材料和身体观察，默认先进入聊天分析。它们可以被拆成支线任务或故事训练素材，但不会自动变成固定公开功能。

## 故事训练

故事训练按 `STORY_TRAINING_PLAN.md` 或个人目录下的 `user-space/STORY_TRAINING_PLAN.md` 执行。

每次故事默认：

- 只讲一个主概念。
- 使用一种写法：莫言式、契诃夫式、莫泊桑式、欧亨利式，或用户指定。
- 只善意提醒一个和用户直接相关的点。
- 另外两个应用场景尽量使用泛化案例或外部案例，避免天天强戳用户。
- 最后给开放作业，用来验收是否真的学会迁移。

## 个人数据安全

`user-space/` 不应提交到公开仓库。

如果要备份个人数据，请自行加密或放到私人仓库。
